# test · 几猫3A大作

一个纯前端、零依赖的 **WebGL 第一人称战术演示**，整包就是单个 `index.html`（three.js 已内联，无需构建、无需后端）。

**在线试玩：** <https://test.heyoucai.site/>

## 内容

- 港口关卡：切断堆场、仓库、码头三处上行中继，然后从码头南端舷梯撤离
- 空中机械飞鸥 + 地面机械猎犬，三波增援，撤离阶段持续追逐
- 完整的 HUD、无线电语音字幕、任务简报 / 结算评级、设置面板（灵敏度、垂直反转、音量、视野、画质、全屏）
- 键鼠（可指针锁定，锁定失败自动降级为拖拽视角）、触屏双摇杆、手柄三套输入

## 运行

```bash
# 直接打开
index.html

# 或起一个静态服务（推荐，避免 file:// 限制）
python -m http.server 8080
```

需要支持 WebGL2 的浏览器。首次进入会自选画质，帧率不足时可在设置里手动调低。

## 调试参数

附带一些用于截图与性能测试的 URL 参数：

| 参数 | 作用 |
| --- | --- |
| `?autostart=1` | 跳过标题直接开局 |
| `?bench=1`（或 `#bench`） | 性能测试模式 |
| `?show=fx\|weapon\|enemies\|level` | 单独展示某个模块 |
| `?cam=x,y,z,tx,ty,tz` `&fov=60` | 固定机位取景 |
| `?q=low\|medium\|high\|ultra` | 强制画质 |
| `?noaudio=1` `?noweapon=1` | 静音 / 隐藏武器 |

`window.__stats()` 可查看 FPS 与渲染统计。

## 部署

仓库根目录即站点根目录，由 GitHub Pages 从 `main` 分支发布，自定义域名见 `CNAME`。推送到 `main` 后自动构建，通常 1 分钟内生效。
